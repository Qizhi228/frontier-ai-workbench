# Frontier AI Workbench 产品规格

## 产品定位

面向单个 AI 应用开发者的前沿技术研究工作台：用户输入一个主题，系统收集可靠来源、提取关键信息、生成带引用的技术简报，并保存到个人知识库。

## 已确认边界

- 单用户，不做注册、计费和多人协作
- 支持“立即执行”和简单每日任务
- 初始来源以官方博客、官方文档、GitHub、Hugging Face、arXiv 为主
- 第一版只做信息检索、分析和文件保存，不自动执行代码或部署
- 默认 Mock 模式，可选 OpenAI 兼容模型
- 复用现有腾讯云服务器，网站和 API 共用 Nginx 入口

## 已确认公开测试边界

1. `ResearchService.run_now(goal)`：生成带来源、关键变化、业务意义和限制的报告，并持久化 Markdown。
2. `SourceCatalog.discover(goal)`：从配置的来源适配器获得去重后的来源。
3. `TaskScheduler.run_due_once(now)`：只执行到期任务，不重复执行未到期任务。
4. `ApprovalPolicy`：研究和写报告不需要审批；未来的代码修改、发送、删除和部署动作必须审批。
5. API：创建任务、立即执行、查询状态和读取报告。

## 非目标

- 不做通用 ChatGPT 替代品
- 不做自主浏览器控制
- 不做自动代码执行
- 不做复杂多 Agent 协作
- 不把未经验证的模型输出当作事实
